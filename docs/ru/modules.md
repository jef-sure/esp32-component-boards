# Модули

Модуль — это устройство, которое не является самостоятельной платой, а едет на
шине любой выбранной платы. Сегодня есть один: символьный LCD 2004 на
I2C-переходнике PCF8574, распространённый дисплей 20x4 с четырьмя пинами
(VCC, GND, SDA, SCL).

## Включение

```sh
python3 tools/board_select.py jc1060p470 --module lcd2004_pcf8574 .
```

`sdkconfig.defaults` модуля дописывается к `sdkconfig.defaults` платы и задаёт
`CONFIG_BOARD_MODULE_LCD2004_PCF8574=y`. Эта опция есть и в меню, в разделе
*Boards*, под выбором платы. Когда она включена, компонент подтягивает
`jef-sure/hd44780` правилом манифеста и компилирует клей модуля рядом с клеем
платы.

## Использование

```c
struct board_character_display lcd;
if (board_character_display_init(&lcd)) {
    lcd_set_cursor((hd44780_t *)lcd.lcd, 0, 0);
    lcd_write_str((hd44780_t *)lcd.lcd, "hello");
}
```

Дисплей поднимается очищенным, с включённой подсветкой; `lcd.cols` и
`lcd.rows` — его геометрия. Остальное — API hd44780 (`hd44780.h`). Модуль
использует I2C-мастер платы, разделяемый с тач-панелью и кодеком платы; адрес
переходника — в данных модуля (`0x27`; переходнику с иначе выставленными
перемычками адреса нужно изменить данные).

На плате без модуля `board_character_display_init` отвечает `false`: одна и та
же программа работает с LCD и без него.

## Как он описан

`boards-data/lcd2004_pcf8574/board.json` — это плата с `"module": true`, без
чипа, без шин и без кнопки, и с символьным дисплеем, чья шина — `i2c.i2c0`
платы-носителя:

```json
{
    "format": "jef-sure/boards", "format_version": 1,
    "name": "lcd2004_pcf8574",
    "title": "2004 character LCD on a PCF8574 backpack",
    "description": "...",
    "display": { "driver": "hd44780", "geometry": "20x4", "bus": { "bus": "i2c.i2c0", "address": "0x27" } },
    "module": true
}
```

Его клей определяет только функцию своего рода,
`board_character_display_init`. У клея каждой платы эта функция тоже есть,
отвечающая `false`, но под `#if !CONFIG_BOARD_MODULE_CHARACTER_DISPLAY`, так
что когда модуль включён, версия платы отступает, и компонуется версия модуля.
Плата, на которой HD44780 распаян (на I2C или на GPIO), описывает его в
собственном `display` и сама определяет настоящую функцию; тогда модуль не
нужен.

## Добавление модуля

Другой символьный дисплей на переходнике — это другой каталог со своей
геометрией и адресом. Модулю другого рода (датчику, радиомодулю) нужен род в
`boards.h`, ветка в генераторе и символ возможности; это форма,
запланированная на следующую версию, где устройства — список, а не один слот
на род.
